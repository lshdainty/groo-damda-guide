# 프리셋

자주 입력하는 거래(점심 · 커피 · 교통비, 비상금 넣기 같은 이체 등)를 프리셋으로 저장해 두면, [거래 추가](../expense/transactions.md#프리셋으로-빠르게-넣기) 창 1단계의 **프리셋** 줄에서 한 번 눌러 칸을 채울 수 있습니다. 프리셋은 **칸만 채울 뿐 거래를 바로 만들지 않습니다** — 채워진 값을 확인하고 2단계에서 **[추가]** 를 눌러야 저장됩니다.

- **데스크톱**: 위쪽 바의 톱니바퀴 → 설정 왼쪽 목록의 **프리셋 관리**
- **모바일(웹 · 앱)**: **전체 → 개인화 → 프리셋**, 또는 **설정 → 데이터 관리 → 프리셋 관리**

## 화면 구성

- **제목** — "프리셋 N개". 요약 숫자 상자는 없습니다
- **정렬**: **많이 쓴 순**(처음 선택) · **최근 사용**(한 번도 안 쓴 프리셋은 맨 뒤) · **이름순**. 오른쪽 위(모바일은 맨 위 오른쪽)에 **[+ 프리셋 추가]**(모바일은 **[추가]**)
- **목록의 한 줄**
  - 왼쪽에 카테고리 색 아이콘(이체는 ⇄ 아이콘)과 이름
  - 아래 줄은 카테고리(이체는 "보내는 계좌 → 받는 계좌")
  - 오른쪽에 고정 금액(저장해 둔 금액이 없으면 **금액 비움**)과 사용 횟수("N번")
- **행에서 할 수 있는 일**: 줄을 누르면 **프리셋 상세**(종류 · 카테고리 · 기본 내역 · 계좌·카드 · 결제 수단 · 메모 · 고정 지출 여부, 이체는 보내는 계좌 · 받는 계좌 · 수수료 · 이자)가 열리고, 맨 아래 **[삭제]** · **[수정]** 으로 지우고 고칩니다(데스크톱 · 모바일 같음). 모바일은 줄을 **왼쪽으로 밀어도** **[수정] · [삭제]** 가 나옵니다. 줄 끝에는 별도 아이콘이 없습니다

**사용 횟수**는 거래 추가 창에서 프리셋을 불러와 **"○○ 적용됨"** 표시가 붙은 채로 거래를 저장할 때마다 1씩 늘고, 그 시각이 **최근 사용**이 됩니다. 적용한 칩을 다시 눌러 풀었거나, 불러온 뒤 카테고리(대분류) · 결제 수단 · 계좌 · 할부 · 통화를 바꿔 표시가 풀린 채 저장한 거래는 세지 않습니다.

[금액 가리기](./account.md#금액-가리기)의 **기타** 탭에서 **프리셋**을 고르면 앱의 프리셋 목록 금액이 가려집니다. 웹의 프리셋 화면과 앱의 상세 창에는 아직 적용되지 않습니다.

## 프리셋 생성

1. **[+ 프리셋 추가]** 를 누르면 **프리셋 추가** 창이 열립니다
2. 칸을 채웁니다. 이름을 뺀 칸은 줄을 누르면 같은 창 안에서 고르는 화면으로 들어가고, 고르거나 적은 뒤 **[완료]**(← 는 그 화면에서 고른 것을 버립니다)로 돌아옵니다

| 칸 | 설명 |
|---|---|
| **유형** | 지출 · 수입 · **이체** 칩. 이체는 [아래](#이체-프리셋)에서 따로 다룹니다 |
| **프리셋 이름** | 칩 아래 입력칸("예: 점심 도시락"), **12자까지**(아래에 "N/12"). 이미 있는 이름이면 "같은 이름의 프리셋이 이미 있어요." 가 뜨고 저장되지 않습니다. 지운 프리셋의 이름은 다시 쓸 수 있습니다 |
| **카테고리** | 꼭 골라야 합니다("카테고리를 골라주세요."). 줄을 누르면 대분류 아래 세부 카테고리 목록이 열립니다 |
| 기본 내역 | 불러올 때 **거래처** 칸에 들어갈 값 |
| 계좌 · 카드 | 여기서는 결제 수단과 상관없이 모든 자산이 나옵니다("계좌 · 카드 없음"으로 비울 수 있습니다) |
| 결제 수단 | 현금 · 카드 · 계좌이체 · 기타 |
| **금액** | 줄을 누르면 금액을 적는 화면이 열립니다. **적어 두면** 불러올 때마다 그 금액이 채워지고(1원 ~ 100억 원), **비워 두면**("비워 둠") 불러올 때 금액 칸이 비어 있습니다 — "비워 두면 불러올 때 금액을 직접 넣어요." 매번 다른 금액일 때 편합니다 |
| 메모 | 불러올 때 거래의 **메모** 칸에 들어갈 값입니다(프리셋 설명이 아닙니다) |
| **고정 지출로 기록**(수입은 **고정 수입으로 기록**) | 이체가 아닐 때만 나오는 스위치입니다. 켜 두면 이 프리셋을 불러올 때 거래 추가 창의 **고정 지출** 스위치가 켜진 채 채워지고, 그렇게 저장한 거래가 통계의 고정 항목이 됩니다 — "이 프리셋으로 만든 거래가 통계의 고정 항목으로 잡혀요." **금액을 저장해 둘지와는 별개**입니다(금액은 *채울 값*, 이쪽은 *통계에서 어느 쪽으로 셀지*) |

3. **[추가]** — 이름과 카테고리(이체는 두 계좌)가 있어야 저장되고, 빠진 칸 아래에 "이름을 입력해주세요." · "카테고리를 골라주세요." 같은 안내가 뜹니다

## 이체 프리셋

유형에서 **[이체]** 를 고르면 카테고리 · 기본 내역 · 결제 수단 · 계좌·카드 대신 **보내는 계좌 · 받는 계좌 · 금액 · 수수료** 를 미리 정해 둡니다(메모는 그대로 있습니다). 늘 같은 두 계좌 사이에서 금액만 바꿔 옮길 때(비상금 넣기, 생활비 통장으로 이체 등) 편합니다.

</TabItem>
<TabItem value="mobile" label="모바일">

![프리셋 추가의 이체 유형(모바일) — 보내는 계좌 · 받는 계좌 · 금액 · 수수료](/img/screens/mobile-settings-preset-transfer-form.png)

- [거래 추가의 이체](../expense/transactions.md#이체--내-계좌-사이에서-돈-옮기기)와 규칙이 같습니다 — **카드는 목록에 없고**("반복·프리셋 이체에는 카드를 고를 수 없어요. 카드 결제는 자동 결제가 맡아요"), 받는 계좌 목록에서는 보내는 계좌로 고른 계좌가 빠집니다
- **이자** 칸은 **받는 계좌가 대출**이고 **금액을 적어 두었을 때만** 나타납니다. 금액이 매번 다르면 이자도 매번 달라지므로, 금액을 비우면 적어 둔 이자도 지워집니다. 수수료는 금액과 상관없이 저장됩니다

:::info[금액을 비워둔 채로 저장할 수 있어요]
**금액**을 비워 두면 금액 없이 저장됩니다 — 금액 검사는 프리셋을 저장할 때가 아니라 **불러와서 이체를 저장할 때** 합니다. 목록에는 "금액 비움"으로 표시되고, 불러오면 두 계좌 · 수수료 · 메모만 채워진 채 금액 칸이 비어 있습니다. 매달 넣는 금액이 달라지는 저축 이체에 맞는 방식입니다.
:::

## 거래 추가에서 불러오기

[거래 추가](../expense/transactions.md#프리셋으로-빠르게-넣기) 창 **1단계의 프리셋 줄**에는 **지금 고른 종류(지출 · 수입 · 이체)의 프리셋만** 많이 쓴 순으로 **8개까지** 칩으로 뜹니다 — 종류가 다른 프리셋을 잘못 눌러 엉뚱한 값이 채워지지 않게 하기 위해서입니다. 프리셋이 8개보다 많으면 칩 끝의 **[모두 보기]** 로 전체 목록에서 고릅니다. 거래를 수정할 때는 이 줄이 나오지 않습니다.

칩을 누르면

- 카테고리 · 계좌·카드 · 거래처(기본 내역) · 결제 수단 · 메모가 프리셋 값으로 **채워집니다**(이체는 두 계좌 · 수수료 · 이자). 프리셋에 없는 칸은 비워지고, 날짜 · 시간은 그대로입니다
- **금액**은 프리셋에 금액이 있을 때만 채워지고, 아니면 **비워집니다** — 금액을 저장하지 않은 프리셋을 고르면 "○○ 프리셋은 금액이 비어 있어요. 금액을 넣고 [다음]을 눌러주세요." 가 붙습니다
- 줄 제목이 **"○○ 적용됨"** 으로 바뀝니다. 적용한 칩을 다시 누르면 풀리고(채운 값을 되돌리지는 않고 표시만 지웁니다, 그 거래는 사용 횟수에 세지 않습니다), 다른 칩을 누르면 그 프리셋으로 바뀝니다
- **앱**은 금액이 있는 프리셋을 불러오면 금액 칸이 **프리셋 잠금**으로 잠기고, 다른 금액을 넣으려면 창을 닫고 다시 여는 방식입니다. 웹은 채워진 금액을 그대로 고칠 수 있습니다

지금 종류에 프리셋이 없으면 "저장된 프리셋이 없어요. 값을 넣고 [현재 입력값 저장]을 누르면 만들어져요." 가 나옵니다.

### 지금 입력한 값을 프리셋으로 저장

같은 줄 오른쪽 **[현재 입력값 저장]** 을 누르면 **프리셋으로 저장** 창이 열립니다. 카테고리(이체는 보내는 계좌와 받는 계좌)를 먼저 골라 두어야 합니다 — 비어 있으면 "카테고리를 먼저 골라주세요." · "보내는 계좌와 받는 계좌를 먼저 골라주세요." 가 뜹니다.

1. **프리셋 이름**을 적습니다("예: 점심 도시락")
2. **금액** 줄 — 지금 적어 둔 금액을 프리셋에 담으려면 금액을 넣습니다. 비워 두면("비워 둠") 금액 없는 프리셋이 되고, 불러올 때 금액을 직접 넣습니다
3. **[저장]** — 카테고리 · 계좌 · 거래처 · 결제 수단 · 메모(이체는 두 계좌 · 수수료 · 메모)는 지금 입력한 그대로 저장되고 "○○ 프리셋을 저장했어요." 가 뜹니다

이 창은 설정의 [프리셋 추가](#프리셋-생성)와 달리 이름을 미리 12자로 막지 않습니다. 이름이 비어 있으면 "프리셋 이름을 입력해주세요.", 같은 이름이면 "같은 이름의 프리셋이 있어요." 가 뜹니다. 12자가 넘는 이름은 저장되지만 나중에 [수정](#프리셋-수정) 창에서는 12자 이내로 줄여야 저장됩니다.

## 프리셋 수정

줄을 눌러 연 **프리셋 상세**의 **[수정]**(모바일은 줄을 밀어서 나오는 **[수정]** 도 됩니다)을 누릅니다. 추가할 때와 같은 폼이 **프리셋 수정** 이라는 제목으로 저장된 값이 채워진 채 열려, 유형 · 이름 · 카테고리 · 기본 내역 · 계좌·카드 · 결제 수단 · 금액 · 메모를 모두 바꾸고 **[저장]** 을 누릅니다.

- 비워서 저장한 칸(기본 내역 · 결제 수단 · 계좌 · 금액 · 메모)은 실제로 지워집니다
- 고친 내용은 앞으로 불러올 때부터 쓰입니다. 이 프리셋으로 이미 저장한 거래는 바뀌지 않고, 사용 횟수도 그대로입니다
- **앱에서는 지출 · 수입 프리셋을 이체로 바꿔 저장할 수 없습니다** — "거래 유형(수입/지출)과 카테고리 유형이 맞지 않아요" 가 뜹니다. 웹에서 바꾸거나 이체 프리셋을 새로 만드세요
- 거래 추가 창에서 12자가 넘는 이름으로 저장한 프리셋은, 웹에서는 이름을 12자 이내로 줄여야 저장됩니다(앱은 이름 칸을 건드리지 않으면 그대로 저장됩니다)
