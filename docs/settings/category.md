# 카테고리 관리

거래내역에 붙이는 수입 · 지출 카테고리를 관리합니다. 카테고리는 [예산](../expense/budget.md) 한도와 [통계](../expense/stats.md) 화면에서도 그대로 쓰입니다.

가입하면 지출 8개(식비 · 카페·간식 · 교통 · 주거·통신 · 생활 · 쇼핑 · 건강 · 문화·여가)와 수입 3개(급여 · 용돈 · 부수입)가 미리 들어 있습니다. 이름은 한국어로 고정이라 언어를 바꿔도 번역되지 않습니다.

## 화면 구성

- **지출 · 수입 탭**: 종류별로 따로 관리합니다(지출 카테고리를 수입 거래에 쓸 수 없고 그 반대도 마찬가지입니다)
- **카테고리 검색**: 이름으로 바로 찾기
- **"지출 카테고리 N개"** 제목 줄 오른쪽의 **[순서 바꾸기]**
- **2단계 구조**: 대분류(최상위) 아래 세부 카테고리를 한 단계까지만 둘 수 있습니다. 하위가 있는 대분류는 왼쪽 꺾쇠(⌄)로 펼치고 접습니다
- **행을 누르면 수정 창**이 열립니다. 행 끝에 연필 · 휴지통 같은 아이콘은 없고, 하위 추가 · 거래 옮기기 · 삭제는 수정 창 머리의 **⋮** 에 있습니다

## 카테고리 생성

1. **[+ 카테고리 추가]** 를 누릅니다 — 데스크톱은 제목 줄 오른쪽, 모바일은 위쪽 바 오른쪽 **[추가]** 입니다. 대분류 행을 눌러 연 수정 창의 **⋮ → 하위 카테고리 추가** 로 그 아래 하위를 바로 만들 수도 있습니다
2. **이름**을 입력합니다 — 최대 12자(칸 아래에 글자 수가 보입니다). 왼쪽 타일에 고른 색 · 아이콘이 미리 보입니다. 비우면 "이름을 입력해주세요.", 같은 종류 · 같은 상위 아래에 같은 이름이 있으면 "같은 자리에 같은 이름의 카테고리가 있어요." 로 막힙니다(지출 '이자'와 수입 '이자'는 둘 다 만들 수 있습니다)
3. **종류**(지출 · 수입)를 고릅니다 — 보고 있던 탭이 처음 값입니다
4. **상위 카테고리**를 고릅니다 — **최상위** 면 부모 없는 대분류가 됩니다. 후보는 같은 종류의 대분류뿐입니다
5. **색상**과 **아이콘**을 고릅니다 — 색은 아직 안 쓴 색이 먼저 골라져 있습니다
6. **[추가]**

:::

## 순서 바꾸기

목록 제목 줄의 **[순서 바꾸기]**(데스크톱 · 모바일 모두)를 누르면 검색칸 자리에 "손잡이를 끌어 순서를 바꿔요. 상위는 상위끼리, 하위는 같은 상위 안에서 옮겨요." 안내가 나오고 행 오른쪽에 **끄는 손잡이(⠿)** 가 생깁니다. 대분류끼리, 같은 대분류 아래 하위끼리만 움직이고, 다른 대분류 밑으로 옮기지는 못합니다 — 그럴 땐 수정 창의 **상위 카테고리**를 바꾸세요. 다 옮겼으면 같은 자리의 **[완료]** 를 누릅니다. 이 모드에서는 행을 눌러도 수정 창이 열리지 않습니다.

## 카테고리 수정

행을 누르면 **카테고리 수정** 창이 열립니다(모바일은 아래에서 올라오는 시트). **이름 · 색상 · 아이콘**을 바꾸고 **[저장]** 합니다. **종류**는 보기만 되고 바꿀 수 없습니다. **상위 카테고리**는 하위 카테고리만 다른 대분류로 바꿀 수 있고(대분류는 "최상위" 로 고정) — 옮겨 갈 대분류의 이번 달 예산을 넘기게 되면 "예산 초과 확인" 창이 한 번 더 묻습니다.

창 머리 오른쪽 **⋮** 를 누르면 **하위 카테고리 추가**(대분류에만), **삭제**, 그리고 **거래 옮기기**(하위가 없는 카테고리에만)가 나옵니다.

:::info[최상위로 올리거나 다른 카테고리 밑으로 넣을 수는 없어요]
- **하위 → 최상위**: 상위 카테고리 목록에 "최상위" 가 없고 "최상위로 올리려면 새 최상위를 만들어 거래를 옮겨주세요." 안내가 붙습니다. 안내대로 **새 대분류를 만들고**, 원래 하위의 **⋮ → 거래 옮기기 → 기존 카테고리로**에서 그 새 카테고리를 고른 뒤, 빈 하위를 지우세요.
- **최상위 → 다른 카테고리의 하위**: 대분류의 상위 카테고리 칸은 "최상위" 로 고정돼 바꿀 수 없습니다. 원하는 대분류 밑에 하위를 새로 만들고, 거래를 옮긴 뒤 원래 대분류를 지우세요.
- 하위 카테고리의 지출 · 수입 구분은 상위와 같아야 합니다.
:::

## 거래 옮기기

수정 창 머리 **⋮ → 거래 옮기기**(데스크톱 · 모바일 모두)는 그 카테고리에 달린 **거래 · 반복 거래 · 나눈 거래를 한꺼번에** 다른 카테고리로 옮깁니다. 하위 카테고리가 있는 대분류에는 거래가 직접 달릴 수 없어 이 메뉴가 나오지 않습니다.

- **새 하위 만들기** — 열면 기본으로 선택됩니다. **만들 하위 이름**(예: 강의, 최대 12자)만 넣고 **[옮기기]** 를 누르면, 그 이름의 하위를 만들고 거래를 모두 그리로 옮깁니다("○○ 아래에 만들고 거래를 모두 그리로 옮겨요. 그러면 다른 하위도 만들 수 있어요.")
- **기존 카테고리로** — **옮길 카테고리**를 골라 모두 옮깁니다. 같은 종류의 가장 아래 단계 카테고리만 고를 수 있고, 옮길 곳이 없으면 "옮길 수 있는 카테고리가 없어요. 먼저 하나 만들어주세요." 가 뜹니다.

끝나면 "N건을 옮겼어요." 가 뜹니다.

:::

## 카테고리 삭제

1. 수정 창 머리 **⋮ → 삭제** 를 누릅니다(데스크톱 · 모바일 같습니다)
2. **"○○" 카테고리를 삭제할까요?** 확인 창이 뜹니다. "이미 기록된 거래는 삭제되지 않고 그대로 남아요. 이 카테고리에 걸린 예산은 함께 삭제돼요." 가 보이고, 이 카테고리를 쓰는 반복 거래가 있으면 "이 카테고리를 쓰는 반복 거래 N개는 계속 이 카테고리로 기록돼요." 가 더해집니다. **[삭제]** 로 확정합니다
3. 하위 카테고리가 있으면 **"삭제할 수 없어요"** 창이 뜹니다 — 하위부터 정리하세요

![카테고리 삭제 확인](/img/screens/category-delete-confirm.png)

:::danger[카테고리를 지워도 거래는 남아요]
카테고리를 삭제해도 그 카테고리로 기록된 거래는 지워지지 않습니다. 대신 그 카테고리는 카테고리 목록 · 거래 입력 · 필터에서 사라져 새 거래에는 더 고를 수 없고, 걸려 있던 **예산도 모든 달에서 함께 삭제**됩니다. 이미 쓴 거래의 분류를 옮기고 싶다면 지우기 전에 **⇄ 거래 옮기기**로 다른 카테고리에 옮겨 두세요. 이름만 바꾸려면 삭제 대신 **수정**을 쓰면 기존 거래의 분류가 그대로 유지됩니다.
:::
