# 증권사 연동하기

토스증권 · 나무증권에서 발급받은 **본인 API 키**를 등록하면 보유 종목과 시세를 담다 안에서 바로 볼 수 있습니다. [담다 Pro 구독](../subscription/subscription.md)이 필요합니다.

## 연동 방법

1. 구독이 안 되어 있다면 먼저 Pro를 구독합니다
2. **설정 → 계정 → 증권 데이터 연동 → 증권사 연동**("토스 · 나무 등 증권사 API 키를 연결해요")을 누릅니다 — 이 줄은 Pro일 때만 보입니다. 데스크톱은 가운데 창이, 모바일은 아래에서 시트가 올라옵니다. 증권 화면의 "증권사를 연결해주세요" 안내에서 **[증권사 연결하기]** 를 눌러도 설정의 계정이 바로 열립니다

3. 첫 단계는 **줄 목록**입니다. 증권사마다 줄이 하나씩 있고, 오른쪽에 ›가 붙어 있습니다. 연결 전에는 "연결 안 됨", 연결한 뒤에는 "연결됨 · ○○ 확인"(확인한 날짜)이 보이고, 기본 증권사에는 이름 옆에 **기본** 표시가 붙습니다. 줄 목록은 서버가 주기 때문에 증권사가 늘어나면 줄만 늘어납니다
4. 연결할 증권사 줄을 누르면 같은 창 안에서 **키 입력 단계**로 넘어갑니다. 칸 이름은 증권사마다 다릅니다

| 증권사 | 첫째 칸 | 둘째 칸 | 발급받는 곳 |
|---|---|---|---|
| 토스증권 | Client ID | Client Secret | 토스증권 개발자센터 |
| 나무증권 | App Key | App Secret | 나무증권 NH PLUG |

5. 두 칸을 모두 채우면 **[연결하기]** 가 눌립니다. 칸 오른쪽 눈 아이콘("○○ 보기")으로 입력한 값을 확인할 수 있습니다. 칸 아래에는 "키는 서버에 암호화되어 저장되고 본인만 사용해요. 발급은 토스증권 개발자센터에서 받을 수 있어요." 가 붙습니다
6. 연결되면 "토스증권 연결을 마쳤어요." 가 뜨고, 같은 자리가 **연결된 상태 화면**으로 바뀝니다 — "토스증권 API 키 연결됨"과 "○○ 확인"(확인한 날짜, 없으면 "보유 주식 · 시세 자동 수집 중")이 보입니다
7. 입력하던 중에 ←를 누르면 "작성한 내용이 사라져요" 확인이 뜨고, **[나가기]** 를 누르면 쓰던 키를 버리고 줄 목록으로 돌아갑니다

증권 화면 쪽에서는, 연결한 증권사가 하나도 없을 때 "증권사를 연결해주세요" 안내와 **[증권사 연결하기]** 가 나옵니다. 웹은 설정의 **계정**이 바로 열리고, 앱은 연동 화면이 바로 열립니다.

:::info[연결하기를 누르는 순간 실제로 확인합니다]
키는 저장하기 전에 그 자리에서 증권사 서버에 실제로 접속해 확인합니다. 잘못된 키면 칸 위에 "인증정보가 올바르지 않아요." 가 뜨고 저장되지 않으므로(쓴 값은 그대로 남아 고쳐서 다시 누를 수 있습니다), "일단 등록해 두고 나중에 화면을 열었을 때 안 되는" 상황은 생기지 않습니다. 응답을 못 받았을 때는 "연결됐는지 확인하지 못했어요." 가 뜨므로 줄 목록에서 연결 상태를 확인하세요.
:::

키는 서버에 암호화되어 저장되고, 등록한 뒤에는 화면에 다시 보여 주지 않습니다(연결됐는지만 표시).

## 두 곳을 연결했다면 — 기본 증권사

토스와 나무를 **둘 다** 연결하면, 기본이 아닌 증권사의 연결된 상태 화면 아래에 **[기본으로 쓰기]** 가 생깁니다("가계부 자산은 여기서 고른 증권사 시세로 계산해요."). 누르면 "이제 ○○ 시세로 자산을 평가해요." 가 뜨고 그 증권사에 **기본** 표시가 붙습니다. 하나만 연결했을 때는 이 버튼이 나오지 않습니다.

- [자산](../asset/overview.md)의 투자 자산 금액은 이 **기본 증권사의 시세**로 계산됩니다
- 증권 화면은 두 증권사를 따로 보여 줍니다 — 데스크톱은 왼쪽 메뉴 **증권** 아래에 증권사가 하나씩, 모바일은 증권 화면 맨 위 탭으로 고릅니다. 처음 열 때는 기본 증권사가 먼저 나옵니다

## 나무증권을 쓴다면 — 알림톡에 대해

나무증권은 접속 권한(토큰)을 새로 발급할 때마다 **등록된 휴대폰으로 카카오 알림톡**을 보냅니다. 나무증권 자체의 보안 정책이라 담다가 막을 수 있는 부분이 아닙니다.

- 나무 접속 권한은 **24시간** 동안 유효합니다. 담다는 한 번 받은 권한을 저장해 두고 끝날 때까지 다시 쓰므로, 화면을 열 때마다 알림톡이 오지는 않습니다
- 새로 발급하는 건 권한이 끝났거나 증권사가 무효라고 알려 왔을 때뿐이라, 평소에는 **하루 한 번 정도**입니다. 키를 처음 연결할 때도 확인하느라 한 번 옵니다
- 토스증권은 이런 알림이 없습니다

## 연동 해제

연결된 증권사 줄을 눌러 상태 화면으로 들어가 **[연결 해제]** 를 누르면 "○○ 연결을 해제할까요?" 확인이 뜹니다 — "해제하면 이 증권사의 보유 주식과 시세를 더 이상 가져오지 않아요. 다시 연결하려면 키를 새로 입력해야 해요." 여기서 **[연결 해제]** 를 누르면 "연결을 해제했어요." 가 뜨고 줄 목록으로 돌아갑니다(그만두려면 **[취소]**). 다시 연결하려면 키를 새로 입력해야 합니다.

## 내 프로그램에서 쓰기 — API 토큰

줄 목록 아래 **내 프로그램에서 쓰기** 묶음의 **API 토큰** 줄(오른쪽에 "없음" 또는 "○개")은 내가 만든 프로그램이 시세를 불러올 때 쓰는 열쇠를 관리하는 곳입니다. 증권사 하나에 묶이지 않아서, 증권사 연결이 하나도 없어도 이 줄은 보입니다.

- **토큰 이름**을 쓰고 **[토큰 만들기]** 를 누르면 "토큰을 만들었어요" 와 함께 토큰 원문이 나옵니다. "지금만 볼 수 있어요. 닫으면 다시 확인할 수 없으니 먼저 복사해 두세요." — **[토큰 복사]** 로 복사하고 **[확인]** 으로 닫습니다. 복사하지 않고 닫으려 하면 "토큰을 복사하지 않았어요 · 닫으면 이 토큰을 다시 볼 수 없어요." 확인이 한 번 더 뜹니다. 같은 화면에 **호출 예시**도 나옵니다
- 목록의 토큰마다 "발급 ○○", "마지막 사용 ○○"(안 썼으면 "아직 안 썼어요")이 보이고, **[폐기]** 를 누르면 "○○ 토큰을 폐기할까요?" 확인 뒤 "토큰을 폐기했어요." 가 뜹니다. 폐기하면 "이 토큰을 쓰던 프로그램은 바로 시세를 불러오지 못해요. 되돌릴 수 없어요."
- API 토큰은 웹(모바일 웹 포함)에만 있고 앱에는 없습니다
- 토큰으로는 **시세 · 차트 · 환율 조회만** 할 수 있습니다. 잔고와 가계부는 열리지 않고, 구독이 끝나면 토큰도 함께 멈춥니다
