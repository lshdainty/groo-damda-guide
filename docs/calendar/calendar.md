# 캘린더

일정을 등록하고 확인합니다. 데스크톱은 **월 · 주 · 목록** 세 가지로 보고, 모바일(웹 · 앱)은 월 달력 하나로 봅니다. 할 일과 가계부 거래는 캘린더에 나오지 않습니다 — 거래는 [가계부의 달력 보기](../expense/transactions.md#화면-구성)에서 봅니다.

## 화면 구성

### 데스크톱

- 제목 줄 오른쪽 **[+ 일정 추가]** 로 어느 보기에서나 일정을 만듭니다
- 도구 줄 왼쪽의 **2026년 9월 ▾** 를 누르면 연 · 월을 휠로 골라 이동합니다(1280px 이상은 작은 창, 그보다 좁으면 아래에서 올라오는 창). **주 보기**에서만 그 옆에 **‹ ›** 가 붙어 한 주씩 옮깁니다
- 도구 줄 오른쪽 **[● 3개 ▾]** 로 화면에 보일 캘린더와 공휴일을 고르고([아래](#여러-캘린더-표시--숨기기)), 그 옆 버튼 세 개로 보기를 바꿉니다 — **월 · 주 · 목록**
- 토요일은 파랑, 일요일과 공휴일은 빨강으로 표시됩니다

#### 월 보기

- **날짜 숫자**를 누르면 그날을 고릅니다. 1280px 이상에서는 오른쪽 패널에 그날 일정이 나오고(**일정 N개**), 더 좁으면 격자 아래 카드에 나옵니다. 칸에 다 안 들어가는 일정은 "+N개" 로 묶입니다
- 패널(또는 카드)의 일정을 누르면 패널이 그 일정의 상세로 바뀌고, 위의 **‹ 날짜** 를 누르면 목록으로 돌아옵니다

#### 주 보기

한 주(일 ~ 토)를 7칸으로 나누고 시간 눈금 위에 일정을 놓습니다. 종일 · 여러 날 일정은 맨 위 줄에, 시각이 있는 일정은 시작 ~ 종료 시각에 맞춘 칸에 나오며 지금 시각에는 선이 그어집니다. 일정을 누르면 가운데 창(1280px 미만은 아래에서 올라오는 창)에 상세가 열립니다.

![캘린더 주 보기 — 종일 일정은 맨 위 줄에, 시각이 있는 일정은 시간 눈금 위에 나옵니다](/img/screens/calendar-week.png)

#### 목록 보기

지금 보는 달의 일정을 **날짜별로 묶어 위에서 아래로** 늘어놓습니다. 각 줄에는 제목과 "종일 · 내 캘린더" 같은 부제가 붙고, 공휴일은 "공휴일" 로 나옵니다. **여러 날에 걸친 일정은 걸린 날마다 한 줄씩** 나오고 부제에 "10월 25일~27일" 처럼 전체 기간이 함께 적힙니다. 일정을 누르면 월 · 주 보기와 같은 상세가 열립니다.

![캘린더 목록 보기 — 날짜별로 일정이 모이고, 여러 날 일정은 걸린 날마다 한 줄씩 나옵니다](/img/screens/calendar-agenda.png)

일정이 없는 달은 **"○월 일정이 없어요"** 와 **[일정 추가]** 가 나옵니다. 일정은 있는데 보일 캘린더를 모두 꺼 둬서 비어 보일 때는 "조건에 맞는 일정이 없어요 · 보일 캘린더를 골라보세요" 가 나오고 추가 버튼은 없습니다.

![일정이 없는 달의 목록 보기 — "11월 일정이 없어요" 와 [일정 추가] 버튼](/img/screens/calendar-agenda-empty.png)

### 모바일(웹 · 앱)

- 화면 폭이 768px보다 좁으면 월 보기 하나만 나옵니다 — 주 · 목록 보기는 데스크톱에만 있습니다. 한 화면에 그 달 전체가 보입니다
- 맨 위 **2026년 9월 ▾** 를 누르면 연 · 월을 골라 이동합니다. 오른쪽 칩(보이는 캘린더 수 "N개")으로 표시할 캘린더를 고릅니다
- **날짜를 누르면 그날의 일정** 창이 먼저 뜹니다(공휴일도 함께). 일정을 한 번 더 누르면 같은 창이 상세로 바뀌고(← 로 목록으로), 창 아래 **[일정 추가]** 로 그 날짜에 새 일정을 만듭니다
- 캘린더 화면에서는 아래 탭 바 가운데 **+** 가 거래가 아니라 **일정 추가**를 엽니다

![모바일에서 날짜를 누르면 그날의 일정 목록이 먼저 뜹니다](/img/screens/mobile-calendar-day-list.png)

## 일정 생성

- **데스크톱**: 제목 줄의 **[+ 일정 추가]**(오늘 날짜로), 월 보기에서 **이미 고른 날짜를 한 번 더 누르기**(1280px 이상), 여러 날을 **끌어서 고르기**(그 기간으로), 날 패널의 **[+ 추가]**, 일정이 없는 달의 목록 보기 **[일정 추가]** 로 열립니다
- **모바일**: 아래 탭 바의 **+**, 또는 날짜를 누른 뒤 **[일정 추가]**

데스크톱(1280px 이상)에서는 먼저 **빠른 추가** 창이 뜹니다 — 제목 · 날짜(+ 종일 스위치) · 캘린더 세 칸만 있고, **[저장]** 을 바로 누르면 만들어집니다(종일이 아니면 09:00 ~ 10:00). 더 쓰려면 왼쪽 아래 **[자세히]** 를 눌러 지금까지 쓴 값을 들고 전체 폼으로 넘어갑니다. 모바일과 1280px 미만은 처음부터 전체 폼이 아래에서 올라옵니다.

| 칸 | 설명 |
|---|---|
| **제목** | 꼭 넣어야 합니다(200자까지) — 비우고 저장하면 "제목을 입력해주세요" |
| 캘린더 | 처음엔 **기본 캘린더**. [캘린더 목록](#여러-캘린더-표시--숨기기)에서 숨겨 둔 캘린더는 고를 수 없습니다 |
| 라벨 | 고르지 않으면 "라벨 없음". [라벨](../settings/calendar.md)을 만들어 두지 않았으면 칸 아래에 "라벨은 설정의 캘린더 라벨에서 만들어요" 안내가 붙습니다 |
| 종일 | 처음엔 켜져 있습니다. 끄면 시작 · 종료에 시각 칸(처음엔 09:00 ~ 10:00)이 붙습니다 |
| 시작 · 종료 | 시작을 종료보다 뒤로 옮기면 종료가 따라옵니다 — 종일 일정은 시작일과 같은 날로, 시각이 있는 일정은 **시작 + 1시간**으로 맞춰집니다. 시작이 여전히 종료보다 앞이면 종료는 그대로입니다. 종료를 시작보다 앞으로 옮기고 **[저장]** 을 누르면 종료 칸 아래에 "종료가 시작보다 빠를 수 없어요" 가 뜹니다. 지난 날짜로 등록하는 건 자유롭습니다 |
| 반복 | 반복 안 함 · 매일 · 매주 · 매월 · 매년. **끝나는 날을 정하는 칸은 없어** 한 번 반복하면 계속 이어집니다 |
| 알림 | 5분 전 · 15분 전 · 30분 전 · 1시간 전 · 1일 전 — 여러 개를 함께 고를 수 있습니다([일정 알림](#일정-알림)) |
| 장소 | 500자까지 |
| 설명 | 10,000자까지. 상세에서는 **설명**으로 보입니다 |

날짜 · 시각은 칸을 눌러 **달력**과 **시계**(웹은 5분 단위 휠, 앱은 1분 단위 휠)를 열어 고르고 **[완료]** 를 누릅니다. 모바일 폼에서 장소 · 설명 줄은 누르면 같은 창 안에서 입력 화면으로 넘어가고, 일정 폼은 바깥을 눌러서는 닫히지 않습니다 — 쓴 내용이 있는 채로 닫으면 "작성한 내용이 사라져요" 하고 한 번 묻습니다.

**[저장]** 을 누르면 만들어집니다.

:::

## 일정 확인 · 수정

일정을 누르면 상세가 열립니다. 월 보기(1280px 이상)에서는 오른쪽 패널이 상세로 바뀌고, 주 · 목록 보기는 가운데 창으로 열립니다. 모바일과 1280px보다 좁은 화면은 아래에서 올라오는 창입니다.

- 맨 위에 **제목**과 **D-day**(오늘이면 D-DAY, 지난 일정은 "N일 지남")
- 아래로 **캘린더**(이름 앞에 색 점), **라벨**(있을 때), **종일** 또는 **시작 · 종료**(시각 일정은 같은 날이면 걸리는 시간, 예: "1시간 30분"도 함께), **반복**, **알림**(있을 때), **장소**(있을 때), **설명**(있을 때)이 한 줄씩 나옵니다. 여러 날 종일 일정은 "10월 25일 (일)~10월 27일 (화)" 처럼 기간이 한 번에 보입니다
- 아래 **[삭제] · [수정]** — 공휴일과, 내가 고칠 수 없는 일정(읽기 전용 캘린더의 남의 일정)에는 없습니다

**[수정]** 을 누르면 추가할 때와 같은 폼이 "일정 수정" 으로 열립니다. 수정 폼 아래에도 **[삭제]** 가 있습니다.

:::warning[반복 일정은 "전체"를 고치고 지웁니다]
반복 일정은 회차마다 따로 있는 게 아니라 **일정 하나가 반복해서 보이는 것**입니다. 그래서 어느 회차를 열어 고치든 지우든 **반복 전체에 적용**되고, "이번 회차만" 고르는 선택지는 없습니다. 어느 회차에서 열었든 **그 회차에서 바꾼 만큼** 반복 전체가 따라옵니다.

- 아무 칸도 바꾸지 않고 **[저장]** 하면 그대로입니다
- 시각을 바꾸면 **모든 회차의 시각**이 같이 바뀝니다 — 셋째 회차를 열어 10시를 11시로 옮기면 지난 회차까지 모두 11시가 됩니다
- 날짜를 옮기면 **반복 전체가 같은 만큼** 옮겨집니다 — 매주 월요일 반복의 한 회차를 화요일로 하루 미루면 모든 회차가 화요일이 됩니다
- 반복을 **반복 없음**으로 바꾸면 **열어 둔 그 회차 하나만** 일정으로 남고, 나머지 회차는 캘린더에서 사라집니다
:::

## 일정 삭제

상세의 **[삭제]**(또는 수정 폼의 [삭제])를 누르면 **"○○" 일정을 삭제할까요? 삭제한 일정은 되돌릴 수 없어요.** 확인 창이 뜨고, **[삭제]** 를 누르면 지워집니다. 반복 일정은 "반복 일정이라 모든 회차가 함께 삭제돼요" 로 알려 줍니다.

## 공휴일 표시

대한민국 공휴일은 **매일 낮 12시**(한국 시간)에 자동으로 갱신되고, 빨간 일정으로 표시됩니다. 공휴일도 누르면 상세가 열리지만 고치거나 지울 수는 없습니다. 보고 싶지 않으면 [캘린더 목록](#여러-캘린더-표시--숨기기)의 **공휴일**을 끄세요.

## 여러 캘린더 표시 · 숨기기

데스크톱은 도구 줄 오른쪽의 **[● 3개 ▾]** 칩(보이는 캘린더 수), 모바일도 같은 칩을 누르면 목록이 열립니다.

- **내 캘린더** — 내가 만든 캘린더와 [공유받은 캘린더](../settings/calendar.md#캘린더-공유)가 나오고, 하나씩 눌러 화면에 보일지 켜고 끕니다. 이 선택은 계정에 저장되어 다른 기기에도 똑같이 적용됩니다
- **기타 소스** — **공휴일** 하나입니다
- 맨 아래 **캘린더 관리 · 공유 설정** 으로 [설정 → 캘린더 관리·공유](../settings/calendar.md#캘린더-공유)에 갑니다

![캘린더 목록 드롭다운 — "내 캘린더(기본)"만 체크박스 없이 항상 켜져 있습니다](/img/screens/calendar-visibility-dropdown.png)

:::info[기본 캘린더는 숨길 수 없어요]
**기본 캘린더** 줄에는 켜고 끄는 칸 대신 늘 켜진 표시와 **기본** 표가 붙어 있습니다("기본 캘린더는 숨길 수 없어요"). 새 일정이 처음 들어가는 자리라, 숨기면 방금 만든 일정이 곧바로 안 보이기 때문입니다. 숨겨 둔 캘린더는 일정 추가 창의 캘린더 목록에도 나오지 않습니다.
:::

## 일정 알림

일정에 넣은 알림은 그 시각이 되면 [알림 목록](../settings/notifications.md)(종 아이콘)에 **"(일정 제목) 알림"** 으로 쌓입니다. 휴대폰 푸시나 이메일로는 오지 않습니다.

- 알림 시각은 **일정을 만든 사람의 [기준 지역](../settings/display.md#기준-지역)** 으로 계산합니다(1분 간격으로 확인)
- 알림은 **일정을 만든 사람에게만** 갑니다 — 공유 캘린더의 다른 멤버에게는 가지 않습니다
- **반복 일정은 첫 회차에만** 알림이 옵니다. 다음 회차부터는 오지 않습니다
- [알림 설정](../settings/notifications.md)에서 **일정 알림**을 끄면 오지 않습니다

## 라벨과 공유

일정에 붙이는 라벨은 [설정 → 캘린더 라벨](../settings/calendar.md)에서, 캘린더를 새로 만들고 다른 사람과 함께 쓰는 건 [설정 → 캘린더 관리·공유](../settings/calendar.md#캘린더-공유)에서 합니다 — 캘린더 화면에서는 관리하지 않습니다.

공유 캘린더에서 할 수 있는 일은 권한마다 다릅니다.

| 권한 | 일정 보기 | 일정 만들기 | 남의 일정 고치기 · 지우기 | 내가 만든 일정 고치기 · 지우기 | 멤버 · 캘린더 관리 |
|---|:---:|:---:|:---:|:---:|:---:|
| 소유자 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 편집 가능 | ✓ | ✓ | ✓ | ✓ | — |
| 읽기 전용 | ✓ | — | — | ✓ | — |

고칠 수 없는 일정(읽기 전용 멤버가 본 남의 일정)에는 [수정] · [삭제] 버튼이 아예 나오지 않습니다.
