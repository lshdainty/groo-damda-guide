# 카드 혜택

내가 가진 카드가 아니어도, 여러 카드사의 신용 · 체크카드 혜택을 찾아보고 비교할 수 있는 라이브러리입니다.

## 들어가는 곳

- **데스크톱**: 왼쪽 메뉴의 **카드 혜택**
- **모바일 · 앱**: 아래 탭바의 **전체** → 일상 → **카드 혜택**("신용 · 체크 카드 검색")

- **검색** — "카드 이름, 카드사로 검색" 칸에 카드 이름이나 **카드사 이름**의 일부를 넣으면 바로 좁혀집니다. 칸 오른쪽 ✕ 로 지웁니다.
- **거르기 칩 둘** — **카드 종류 ▾**(전체 · 신용 · 체크)와 **혜택 ▾**(전체 · 할인 · 적립 · 마일리지). 칩을 누르면 그 조건 하나만 열리고, 줄 하나를 누르면 바로 고른 것으로 닫힙니다(데스크톱은 칩 아래 팝오버, 모바일 · 좁은 화면은 아래에서 올라오는 창). 조건을 걸면 칩이 짙게 채워지며 고른 값("신용" · "적립")이 적히고, 하나라도 걸려 있으면 맨 앞에 **↺** 가 나와 조건을 한꺼번에 지웁니다.
- **총 N장** — 지금 조건에 맞는 카드 수
- **단종 카드 포함**(기본 꺼짐) — 켜면 지금은 새로 발급되지 않는 카드도 함께 보여 줍니다. 단종 카드에는 이름 뒤에 **단종** 표시가 붙습니다.

카드마다 카드 그림, 이름, "카드사 · 신용/체크 · 혜택 유형", **연회비**(금액 · 없음 · 정보 없음)와 **실적**("실적 N원" 또는 "실적 없음")이 보입니다. 데스크톱 · 태블릿은 한 쪽에 20장씩 아래의 쪽 번호로 넘기고, 모바일은 내리면 이어서 불러옵니다(한 번에 60장). 맞는 카드가 없으면 "찾는 카드가 없어요 · 다른 검색어나 조건으로 찾아보세요" 가 나옵니다.

:::info[혜택 칩은 카드의 "대표 혜택"으로 거릅니다]
카드마다 **대표 혜택 유형이 하나**(할인 · 적립 · 마일리지)로 정해져 있고, 칩은 그것만 봅니다. 할인 카드에 적립 혜택이 조금 딸려 있어도 **적립**을 고르면 나오지 않습니다. 캐시백이라는 별도 항목은 없습니다.
:::

## 카드 상세 보기

카드를 누르면 그 카드의 상세가 열립니다. **1280px 이상**의 넓은 화면에서는 목록 **오른쪽 자리**가 눌러 고른 카드의 상세로 바뀌고(처음에는 목록 첫 카드), 그보다 좁은 화면과 모바일에서는 **카드 상세** 창이 아래에서 올라옵니다. 바깥을 누르거나 아래로 끌어내리면 닫힙니다.

- 맨 위 카드 그림, 카드 이름, "카드사 · 신용/체크 · 혜택 유형"
- **주요 혜택 태그** — 대표 혜택을 짧은 칩으로
- **연회비**(국내전용 금액 · 무료 · 정보 없음), **전월 실적**("N원 이상" · 실적 없음), **브랜드**(카드 브랜드가 있을 때)
- **혜택 N개** — 혜택마다 분류 · 요약이 한 줄씩 나오고, 자세한 내용이 있는 항목은 누르면 펼쳐집니다. 오른쪽 **[모두 펼치기] / [모두 접기]** 로 한꺼번에 열고 닫습니다. 등록된 혜택이 없으면 "등록된 혜택이 없어요" 가 나옵니다.
- **유의사항** — 카드사가 알려 준 안내 문구가 있을 때 맨 아래에 파란 안내 상자로 나옵니다.

## 여기서 할 수 없는 것

- **추천**이나 "내가 가진 카드" 표시는 없습니다 — 찾아보기 전용입니다.
- 이 화면에서 바로 카드를 등록하는 버튼은 없습니다. 카드는 [설정 → 계좌 · 카드 관리](../settings/account-card.md#카드-생성)에서 등록하고, 그때 **같은 카드 상품 목록**에서 고릅니다. 등록할 때 고른 상품의 **전월 실적 조건**이 [카드 상세](./card.md)의 실적 표시 기준이 됩니다.
